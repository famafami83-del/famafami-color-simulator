# 재생성 도구

평소에는 쓸 일이 없습니다. **`src/build.js` 만 돌리면 페이지가 다시 만들어집니다.**

아래 도구는 **원본 소재가 바뀌었을 때만** 씁니다. 전부 `sharp` 패키지가 필요합니다 (`npm i sharp`).

---

## 1. `extract-masks.js` — 침구 부위 마스크 만들기

**언제:** 배경 사진을 바꿀 때. 또는 부위를 더 나눌 때.

같은 구도에서 **색만 다른 렌더 이미지 3장**을 비교해, 색이 어떻게 변하는지로 부위를 갈라냅니다.
배경(마루·벽·커튼)은 세 장에서 변동이 **정확히 0**이라 자동으로 빠집니다.

```
입력  D:\01. 파마파미\00. 디자인\컬러시뮬레이션\
        80수 915번 브라운.jpg
        무지- 이불2006번 베개 914번.jpg
        901-2014.jpg
출력  base.jpg (흰색으로 되돌린 사진) + mask_*.png 6장
```

**주의 — `VAR_THRESHOLD`**
값이 높으면 **색이 거의 안 변하는 부위가 배경으로 잘려나갑니다.**
실제로 0.055에서 오른쪽 베개(흰색→민트→흰색)가 통째로 빠졌습니다. 현재 **0.018**.

**주의 — 시드 좌표**
부위 위치를 `SEEDS`에 직접 찍어둡니다. 사진이 바뀌면 좌표도 다시 잡아야 합니다.
자동 군집화(k-means)로는 베개들이 갈리지 않았습니다.

## 2. `alpha-masks.js` — 마스크를 투명도 채널로 변환

`extract-masks.js` 다음에 **반드시** 돌립니다.

CSS `mask-image`는 **투명도**를 읽습니다. 흑백 이미지로 두면 브라우저가 마스크를 무시해서
**색을 눌러도 아무 일도 일어나지 않습니다.** 흰색 RGB + 알파 형태로 바꿔줍니다.

## 2-1. `split-quilt.js` — 이불 마스크를 앞면 / 뒷면으로 가르기 (양면 디자인)

**언제:** 배경 사진이나 이불 마스크를 다시 만들었을 때. `alpha-masks.js` **다음에** 돌립니다.

```
입력  mask_quilt.png + D:\...\컬러시뮬레이션\ 의 양면 렌더 3장
출력  mask_quiltA.png (앞면 · 깔린 면) + mask_quiltB.png (뒷면 · 젖혀진 면)
```

양면 렌더 3장은 무지 3장과 **같은 원본**에서 이불 색만 바꿔 뽑은 것입니다. 벽·바닥·창문 픽셀이
정확히 0 차이라 **새 사진도, 새 매트리스·베개 마스크도 필요 없습니다.** 이불만 둘로 가르면 됩니다.

**주의 — 씨앗**
아무 픽셀이나 둘 집으면 둘 다 같은 면에 떨어져 **한 덩어리로 뭉칩니다.** 실제로 그렇게 됐습니다.
색이 가장 크게 갈리는 축(주성분)을 찾아 그 양 끝을 씨앗으로 씁니다.
한쪽이 5% 미만이면 **에러로 멈춥니다** — 앞면만 색이 먹는 페이지가 조용히 나가는 걸 막습니다.

**주의 — 앞뒤 판별**
`앞면(901번 아이보리) 뒷면(2012 블루)` 장에서 **파란 기가 더 센 쪽이 뒷면**입니다.
버터·핑크처럼 둘 다 따뜻한 장으로 판별하면 앞뒤가 뒤집힙니다. `SHOTS` 순서를 바꾸지 마십시오.

## 2-2. `design-cards.js` — 디자인 고르는 카드 사진 만들기

**언제:** 배경 사진·마스크를 다시 만들었을 때. 디자인을 더할 때.

```
입력  base.jpg + mask_*.png
출력  card_plain.jpg · card_both.jpg  (520px 정사각, 각 26KB)
```

**카드 두 장은 같은 색으로 칠하고 젖혀진 면만 다르게 둡니다.** 카드마다 색을 다르게 하면
손님이 「어느 쪽이 예쁜가」를 고르게 되어 디자인 차이가 묻힙니다.

**주의 — `CROP`**
이불 **앞면과 젖혀진 뒷면이 둘 다** 들어와야 양면 카드에서 「두 색」이 보입니다.
침대 전체를 담으면 작은 카드에서 이불이 너무 작아져 차이가 안 보입니다.

## 3. `extract-colors.js` — 컬러차트에서 102색 뽑기

**언제:** 원단 색이 추가·변경될 때.

```
입력  D:\01. 파마파미\06. 협력업체\프린톤(컬러칩작업)\최종 수정본\1차수정분\JPEG\  (13장)
출력  swatches.json
```

번호·영문명·한글명·번수는 **차트 이미지를 직접 읽어 코드 안에 적어둔 값**입니다 (`CHART` 상수).
색상값만 이미지에서 자동으로 뽑습니다.

**주의 — `rowY`**
칩이 놓인 줄의 세로 위치를 비율로 직접 적어뒀습니다. 자동 검출은 제목 줄이 섞여서 실패했습니다.
**차트 레이아웃이 바뀌면 이 값을 다시 재야 합니다.**

## 4. `verify.js` — 합성 결과 확인

브라우저 없이 마스크가 제대로 맞는지 봅니다. 결과는 `verify.jpg`.
**마스크는 투명도 채널을 읽어야 합니다** — 색(RGB)을 읽으면 화면 전체가 물듭니다.

---

## 전체를 다시 만드는 순서

```
node src/tools/extract-masks.js     # 부위 마스크 + 흰색 배경
node src/tools/alpha-masks.js       # 투명도 채널로 변환 (건너뛰면 색이 안 먹힘)
node src/tools/split-quilt.js       # 이불을 앞면·뒷면으로 (건너뛰면 빌드가 멈춤)
node src/tools/design-cards.js      # 디자인 카드 사진 (건너뛰면 빌드가 멈춤)
node src/tools/extract-colors.js    # 컬러 102색
node src/build.js                   # index.html
```

마스크와 색이 그대로면 **마지막 것만** 돌리면 됩니다.
