# 파마파미 컬러 시뮬레이터

침구 색 조합을 웹에서 미리 보고, **맞춤 주문 문의를 한 번에 보낼 수 있게** 만든 페이지입니다.

**→ https://famafami83-del.github.io/famafami-color-simulator/**

기성 상품에 없는 조합은 전부 맞춤 제작입니다. 이 페이지는 **그 맞춤 주문을 받는 창구**입니다.

---

## 쓰는 흐름

| 단계 | 하는 일 |
|---|---|
| **① 색 고르기** | 부위 6곳의 색을 원단 **102색**에서 선택 |
| **② 사이즈** | 이불 · 매트리스커버 · 베개커버 각각 (필요 없는 항목은 「안 할래요」) |
| **③ 확인** | 고른 내용을 **복사해서 문의에 붙여넣기** |

**부위 6곳** — 이불 / 매트리스커버 / 베개(앞)-왼쪽 / 베개(앞)-오른쪽 / 베개(뒤)-왼쪽 / 베개(뒤)-오른쪽

   두께 : 간절기용 (8온스)

■ 매트리스커버
   침대 규격 : 퀸 150×200
   실제 사이즈 : 150x200 / 높이 25
   컬러 : NO. 913 · 친칠라 80수

## 원단 102색

`FAMAFAMI All Color Chart` 13개 그룹을 그대로 옮겼습니다.
각 색은 **번호 · 영문명 · 한글명 · 번수(60/80/100수)** 를 갖고 있어 그대로 주문에 씁니다.

| 그룹 | 색 | 그룹 | 색 |
|---|---|---|---|
| 화이트 · 크림 | 5 | 에이스드 터치 | 4 |
| 라이트 그레이 | 9 | 그린 웨이브 | 13 |
| 딥 그레이 | 15 | 블루 | 9 |
| 어시 레인지 | 17 | 라벤더 | 3 |
| 레드 | 3 | 핑크 | 10 |
| 로즈 와인 | 4 | 번트 오렌지 | 3 |
| 옐로우 | 7 | | |

**매트리스커버는 60수 · 80수만** 고를 수 있습니다 (100수는 얇아서 쓰지 않습니다).
이불 · 베개커버는 102색 전부 가능합니다.

## 고치는 법

```bash
npm i sharp          # 처음 한 번만
node src/build.js    # index.html 다시 만들기
git add -A && git commit -m "..." && git push
```

push하면 몇 분 안에 위 주소에 반영됩니다.

### 폴더 구조

```
index.html      배포되는 페이지. 직접 고치지 말고 build.js로 다시 만든다
colors.json     원단 102색 (공개용)
src/
  build.js      index.html 을 만든다 ← 대부분 여기만 고치면 된다
  swatches.json 컬러 원본 데이터
  assets/       흰색 배경 사진 + 부위 마스크 6장
  tools/        원본 소재가 바뀌었을 때만 쓰는 재생성 도구 (tools/README.md 참조)
```

**`index.html` 을 직접 고치지 마십시오.** `build.js` 를 다시 돌리면 덮어써집니다.
사이즈 목록·부위 이름·안내 문구는 전부 `src/build.js` 위쪽 상수에 모여 있습니다.

### 이미지가 왜 HTML 안에 들어 있나

CSS 마스크는 `file://` 로 열면 외부 이미지를 못 읽습니다. 분리해두면 **로컬에서 색이 안 먹힙니다.**
그래서 사진과 마스크를 전부 base64로 넣었습니다. 그래서 파일이 790KB 정도 됩니다.

## 아직 안 된 것

- **견적(금액) 미구현.** 구조는 정해졌습니다 — *현재 판매가 + 맞춤 추가금*.
  사이즈별 판매가와 맞춤 추가금이 정해지면 붙습니다.
- 색상값은 컬러차트 이미지에서 뽑은 값이라 **화면과 실물이 다를 수 있습니다.** 번호와 이름은 차트 그대로입니다.
- 컬러차트에 **번호가 겹치는 곳 두 군데** — `2027`(애프터 다크 / 다크 그린), `2023`(코코아 그레이 / 쿨 라벤더).
- 배경 사진은 **무지 제품** 한 종류뿐입니다. 스트라이프 · 라인 · 양면 · 날개형은 아직 없습니다.
