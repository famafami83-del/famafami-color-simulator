# 파마파미 컬러 시뮬레이터

침구 컬러 조합을 웹에서 미리 보는 페이지입니다.
이불 · 매트리스커버 · 베개커버의 색을 각각 골라 실제 사진 위에서 확인하고,
고른 조합을 주문서에 넣을 텍스트로 복사할 수 있습니다.

**→ https://famafami83-del.github.io/famafami-color-simulator/**

---

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 전체. **이미지까지 안에 들어 있는 단일 파일**이라 이것만 있으면 어디서든 열립니다 |
| `colors.json` | 원단 컬러 데이터 102색 (번호 · 영문명 · 한글명 · 번수 · 색상값) |

## 원단 컬러 102색

`FAMAFAMI All Color Chart` 13개 그룹을 그대로 옮겼습니다.

| 그룹 | 색 | 그룹 | 색 |
|---|---|---|---|
| 화이트 · 크림 | 5 | 에이스드 터치 | 4 |
| 라이트 그레이 | 9 | 그린 웨이브 | 13 |
| 딥 그레이 | 15 | 블루 | 9 |
| 어시 레인지 | 17 | 라벤더 | 3 |
| 레드 | 3 | 핑크 | 10 |
| 로즈 와인 | 4 | 번트 오렌지 | 3 |
| 옐로우 | 7 | | |

각 색은 `NO. 913 · 친칠라 80수` 형태로 표시되어 **그대로 주문에 쓸 수 있습니다.**

## 부위별 원단 제한

- **매트리스커버는 60수 · 80수만** 고를 수 있습니다. 100수는 얇아서 쓰지 않습니다.
- 이불 · 베개커버는 102색 전부 가능합니다.

## 동작 방식

흰색 침구 사진 한 장에 색을 **곱하기(multiply)** 로 입힙니다.
포토샵에서 컬러 레이어를 씌우는 것과 같은 원리라, **주름과 그림자가 원본 사진 그대로 남습니다.**
색 조합마다 이미지를 따로 만들 필요가 없어 조합 수에 제한이 없습니다.

## 고칠 때

`index.html` 하나만 바꾸면 됩니다. 저장하고 push하면 몇 분 안에 반영됩니다.

## 알려진 것

- 색상값은 컬러차트 이미지에서 뽑은 값이라 **화면과 실물은 다를 수 있습니다.** 번호와 이름은 차트 그대로입니다.
- 컬러차트에 번호가 겹치는 곳이 두 군데 있습니다 — `2027`(애프터 다크 / 다크 그린), `2023`(코코아 그레이 / 쿨 라벤더).
